引程 2.3.5 · 规划工作台
================

安装包：下载 yincheng-2.3.5.apk
包名：app.yincheng.planner
版本：2.3.5

安装
1. 下载「yincheng-2.3.5.apk」到手机。
2. 在文件管理器里点开安装；允许未知来源。
3. 已装过旧版可直接覆盖。

提醒 / 通知 / 闹钟（重要）
1. 打开「设置」→「提醒」→「打开系统通知」，按系统提示授权。
2. Android 13+ 必须允许通知；部分机型还需允许「精确闹钟 / 闹钟和提醒」。
3. 「测试通知」可立刻弹出一条；「精确闹钟」跳转系统权限页。
4. 新建日程时可选「通知」或「闹钟」：闹钟会调起系统时钟 App。
5. 打开通知后，课表未来两周的上课时间也会按提前量提醒。

模型
1. 设置里选接口并填写密钥，点「保存并测试」。
2. 密钥只存在本机。
